# Beecrowd 1060 - Números Positivos

## Descrição

Este programa resolve o problema 1060 do Beecrowd, que consiste em ler 6 valores e contar quantos deles são positivos.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa recebe 6 valores, que podem ser positivos ou negativos.

## Saída

O programa deve imprimir a quantidade de valores positivos lidos, no formato:

X valores positivos
